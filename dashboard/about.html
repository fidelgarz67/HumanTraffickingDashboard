About this project

The Trafficking Risk Identifier began as a Masters Project exploring how data science methods can help examine patterns in human-trafficking-related data.

A project in progress

This site is both a project deliverable and an ongoing effort. The current model and dashboard are an early research prototype. As the work continues, the model, data preparation, explanations, and interface can be reviewed and refined.

Larger datasets may make it possible to study a broader range of contexts, but size alone does not guarantee better results. Any future data should also be relevant, representative, responsibly sourced, and evaluated for quality and bias. Model changes should be tested and documented rather than assumed to improve performance.

Use with care

Human trafficking is complex and underreported, and datasets may reflect gaps in observation and reporting. This project is educational and exploratory; it is not a substitute for expert judgment, survivor-centered practice, or verified evidence. The current dashboard should not be used to assess individuals or make operational decisions.
