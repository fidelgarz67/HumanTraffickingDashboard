What the dashboard displays

The dashboard is an interface for exploring the project’s currently available country-level model summaries—not a live reporting system or an individual risk assessment.

Explore a country

  1. Choose a country from the region menu. The available options depend on the results data currently loaded.
  2. The map marks the selected country using its representative coordinates. The marker is for geographic reference, not a location-level estimate.
  3. The high-risk-features panel lists the most influential features in the current summary for that country. The percentages shown are scaled feature-importance values, not probabilities or percentages of people affected.
  4. The Low/Medium/High label is a simple front-end grouping of the listed importance values. See Methodology for the thresholds and limitations.

Export data

Use the Export menu to download the available summaries as CSV or JSON, either for the selected country or for all countries in the loaded results. Exports contain the data available to the dashboard and should be interpreted with the same limitations as the on-screen summaries.

Coverage and limitations

The current model notebook analyzes five countries, and the interface only displays countries included in its loaded data. The dashboard does not provide live incident reporting, case-level details, or validated estimates of trafficking prevalence. Model explanations describe patterns learned from the available data; they are not proof of causation.
