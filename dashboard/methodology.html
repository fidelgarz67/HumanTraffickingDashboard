Methodology

This page summarizes how the current model and the country-level feature summaries are produced. It is a research prototype, and its outputs should be interpreted with care.

Data and preparation

The project notebook uses the Global K-Anon dataset and, in the current modeling workflow, filters records to five countries of exploitation: the United States, Russia, the Philippines, Indonesia, and Cambodia. The analysis focuses on demographic, recruitment, exploitation-context, and means-of-control fields.

Missing binary indicators are filled with zero, missing categories are labeled “Unknown,” and categorical values are encoded for the model. Records without a known sexual-exploitation label are excluded. These choices are part of the current project implementation and may change as the work develops.

Model and explanation

The notebook trains a feed-forward neural network to classify the dataset’s isSexualExploit label. It uses a stratified 80/20 train-test split, class weighting, and a validation subset during training. The current network has hidden layers of 128, 64, and 32 units with dropout, and is trained for 10 epochs.

SHAP GradientExplainer is applied to test records. For each country, the dashboard data contains the five features with the largest mean absolute SHAP values among test records associated with that country. These values summarize how strongly features contribute to model output in this analysis; they do not show whether a feature raises or lowers an individual prediction.

Important interpretation note

The feature summaries are explanations of model behavior, not evidence that a feature causes trafficking or that a country has a particular prevalence. The dashboard’s Low/Medium/High label is currently assigned in the front end by summing the displayed feature-importance values (below 0.15: Low; 0.15–0.30: Medium; 0.30 or higher: High). It is a presentation heuristic—not a calibrated model probability, a measure of population-level risk, or a validated trafficking-risk score.

This prototype is not designed for individual assessment, operational decisions, or allocation of enforcement or services. Dataset coverage, reporting bias, and model limitations should be considered before drawing conclusions.
